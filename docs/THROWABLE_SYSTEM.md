# 投掷物系统实现文档

## 概述

实现了完整的投掷物系统，包括手雷投掷、瞄准轨迹预览、快捷栏使用等功能。

## 功能特性

### 1. 手雷武器
- **物品ID**: `w_frag_grenade`
- **名称**: 破片手雷
- **稀有度**: COMMON
- **价格**: 150金币
- **堆叠**: 最多5个
- **武器类型**: throwable
- **投掷速度**: 400像素/秒
- **引信时间**: 3秒
- **爆炸半径**: 100像素
- **爆炸伤害**: 80点

### 2. 快捷栏系统
- **快捷键**: 数字键1-5
- **显示位置**: HUD右侧快捷栏区域
- **支持物品**: 
  - 医疗包（绿色边框）
  - 破片手雷（橙红色边框）
- **使用方式**: 按对应数字键即可使用

### 3. 投掷瞄准系统
- **轨迹预览**: 装备手雷时显示抛物线轨迹
- **视觉效果**: 
  - 橙红色虚线轨迹
  - 轨迹点标记
  - 落点十字标记
  - 爆炸半径圆圈
- **物理模拟**: 
  - 重力: 300像素/秒²
  - 最大飞行时间: 3秒
  - 实时轨迹计算

### 4. 使用流程

#### 购买手雷
1. 在HIDEOUT阶段打开商店
2. 找到"破片手雷"物品
3. 点击购买按钮
4. 手雷会添加到仓库

#### 装备手雷
方式1 - 快捷栏使用：
1. 将手雷移动到整备区
2. 进入战局
3. 按数字键1-5使用手雷（自动装备）

方式2 - 背包装备：
1. 在战局中打开背包
2. 点击手雷的"装备"按钮

#### 投掷手雷
1. 装备手雷后会显示投掷轨迹预览
2. 移动鼠标瞄准目标位置
3. 点击鼠标左键投掷
4. 手雷飞行3秒后爆炸
5. 爆炸范围内的玩家受到伤害

### 5. 医疗包使用
- **效果**: 恢复50点生命值
- **限制**: 生命值满时无法使用
- **使用方式**: 快捷栏数字键或背包使用

## 技术实现

### 客户端
- `ThrowingAim`: 投掷瞄准系统
- `InputManager`: 数字键1-5输入处理
- `HUD`: 快捷栏显示
- `Network`: 使用物品消息发送

### 服务端
- `Room.handleUseItem()`: 使用物品逻辑
- 爆炸系统: 复用现有榴弹炮爆炸逻辑
- 物品消耗和装备切换

### 协议
- `C2S_USE_ITEM`: 使用物品消息
- 槽位参数: 1-5对应快捷栏位置

## 平衡性设计

### 手雷特点
- **优势**: 
  - 高爆炸伤害（80点）
  - 范围攻击（100像素半径）
  - 可预测轨迹
- **劣势**:
  - 引信延迟（3秒）
  - 消耗品（一次性使用）
  - 需要预判敌人位置
  - 可能误伤自己

### 战术用途
- 清理掩体后的敌人
- 区域拒止
- 破坏敌人阵型
- 配合其他武器使用

## 测试建议

1. **购买测试**: 在商店购买手雷，检查价格和库存
2. **装备测试**: 通过快捷栏和背包两种方式装备手雷
3. **瞄准测试**: 装备手雷后检查轨迹预览是否正确显示
4. **投掷测试**: 投掷手雷并观察爆炸效果
5. **伤害测试**: 测试爆炸伤害和范围
6. **医疗包测试**: 测试医疗包的恢复效果
