# 地图重叠检测功能

## 功能说明

在加载地图时，系统会自动检测以下类型的区域重叠并输出警告信息：

1. **障碍物之间的重叠** - 检测 wall, bush, crate, water 等障碍物之间的重叠
2. **撤离点与障碍物的重叠** - 检测撤离区域是否被障碍物遮挡

**注意：区域 (zones) 之间的重叠是允许的**，因为区域通常用于逻辑划分（如"中心安全区"和"战利品区"可以重叠），不会被检测。


## 警告信息格式

当检测到重叠时，系统会在控制台输出详细的警告信息，包括：

- 重叠的两个对象的详细信息（类型、位置、尺寸、ID）
- 重叠区域的位置和尺寸
- 重叠面积及其占各对象的百分比

## 触发时机

重叠检测会在以下情况下自动触发：

- 服务器启动加载地图时
- 使用 `reloadMapTemplates()` 重新加载地图时
- 执行任何解析地图模板文本 (`parseMapTemplateText`) 的操作时

## 如何使用这些警告信息

1. **复制警告信息** - 从控制台复制完整的重叠警告信息
2. **提供给 LLM** - 将警告信息提供给 LLM (如 ChatGPT, Claude 等)
3. **请求调整** - 要求 LLM 调整地图配置以消除重叠
4. **应用修复** - 将 LLM 生成的修复后的地图配置应用到地图文件中

## 实现位置

- **检测逻辑**: `shared/src/mapTemplate.ts` 中的 `detectOverlaps()` 函数
- **调用位置**: `parseMapTemplateText()` 函数在解析完成后自动调用

## 注意事项

- 所有障碍物之间的重叠都会被检测并报告
- 撤离点与障碍物的重叠会被检测，特别关注高占比的重叠
- 区域 (zones) 之间的重叠是允许的，不会被检测
- 重点关注占比较高的重叠（>50%）或影响游戏性的重叠
