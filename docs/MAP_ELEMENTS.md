# 地图元素系统

## 概述

地图元素系统为Jerkie Man添加了丰富的战术地形元素，提升游戏深度和策略性。

## 地图元素类型

### 1. 石墙 (Wall) - 坚固障碍
- **颜色**：深灰色 (#666666)
- **玩家穿越**：❌ 不可穿过
- **子弹穿透**：❌ 完全阻挡
- **可破坏**：❌ 不可破坏
- **战术用途**：坚固掩体，完全保护

### 2. 木箱 (Crate) - 可破坏掩体
- **颜色**：棕褐色 (#A0522D)
- **玩家穿越**：❌ 不可穿过
- **子弹穿透**：❌ 完全阻挡
- **可破坏**：✅ HP: 100
- **破损显示**：根据HP显示裂痕（HP<90%: 1条，HP<60%: 3条，HP<30%: 5条）
- **战术用途**：小型掩体，容易被摧毁

### 3. 草丛 (Bush) - 隐蔽区域
- **颜色**：绿色 (#228B22)，半透明
- **玩家穿越**：✅ 可穿过
- **子弹穿透**：✅ 完全穿透
- **可破坏**：❌ 不可破坏
- **视野遮挡**：✅ 提供隐蔽（在草丛内对外不可见）
- **战术用途**：埋伏、隐蔽移动

### 4. 水域 (Water) - 地形屏障
- **颜色**：蓝色 (#4169E1)，半透明
- **玩家穿越**：❌ 不可穿过
- **子弹穿透**：✅ 完全穿透
- **可破坏**：❌ 不可破坏
- **战术用途**：天然屏障，限制移动路线

## 地图生成权重

地图生成时，各类型障碍物的生成概率：

- **草丛**：35% （最常见，提供战术多样性）
- **木箱**：30% （常见，可破坏）
- **石墙**：20% （适中，强力掩体）
- **水域**：10% （少量，大型地形）

总计生成 20-40 个障碍物。

## 技术实现

### 数据结构

```typescript
// Obstacle Schema
{
  id: string;          // 唯一标识
  x: number;           // 位置X
  y: number;           // 位置Y
  w: number;           // 宽度
  h: number;           // 高度
  type: string;        // 类型
  hp?: number;         // 当前生命值
  maxHp?: number;      // 最大生命值
}
```

### 配置文件

障碍物配置在 `shared/src/obstacleConfig.ts`：

- `blocksPlayer`: 是否阻挡玩家
- `blocksBullet`: 是否阻挡子弹
- `bulletPenetration`: 子弹穿透系数 (0-1)
- `providesConcealment`: 是否提供隐蔽
- `destructible`: 是否可破坏
- `maxHp`: 最大生命值

### 碰撞检测

`shared/src/sim.ts` 中的 `simulatePlayerMove` 函数会检查障碍物类型：

```typescript
if (doesObstacleBlockPlayer(obsType) && circleVsAABB(x, y, radius, obstacle)) {
  // 阻挡移动
}
```

### 视觉渲染

`client/src/renderer.ts` 中的 `drawObstacle` 方法根据类型渲染：

- 不同颜色
- 不同透明度
- 特殊图案（草丛的圆点、水域的波纹线）
- 损坏状态显示（HP低时变暗）

## 未来扩展

### 已设计但未实现的功能

1. **草丛视野遮挡系统**
   - 需要实现FOW（战争迷雾）系统
   - 在草丛内的玩家对草丛外的玩家不可见
   - 可在快照中添加可见性字段

2. **可破坏物体系统**
   - 障碍物已有HP字段
   - 需要实现伤害处理逻辑
   - 被破坏后从obstacles数组移除或标记为destroyed

3. **子弹穿透系统**
   - 配置已支持bulletPenetration系数
   - 需要在子弹碰撞检测中应用伤害削弱

4. **物品掉落**
   - 木箱被破坏后可掉落物品
   - 需要在破坏时生成lootBag

## 示例

### 添加自定义地图元素

在 `.map.txt` 文件中（未来功能）：

```
@obstacle type=bush x=100 y=100 w=80 h=80
@obstacle type=water x=500 y=500 w=150 w=150
@obstacle type=crate x=300 y=300 w=40 h=40
```

### 代码中创建障碍物

```typescript
const obstacle = {
  id: 'obs_custom_1',
  x: 100,
  y: 100,
  w: 60,
  h: 60,
  type: 'crate',
  hp: 100,
  maxHp: 100,
};
```

## 性能考虑

- 障碍物数量：20-40个（可调）
- 渲染优化：已使用整数像素坐标
- 碰撞检测：使用AABB算法，O(n)复杂度
- 未来优化：可使用空间分区（Quadtree）

## 兼容性

- 向后兼容：旧地图没有type字段，默认为'wall'
- 协议兼容：type字段可选，老客户端会忽略
